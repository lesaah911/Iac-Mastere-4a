# IaC — Mastère 4A

Ce dépôt regroupe les travaux pratiques du module Infrastructure as Code
du Mastère Cybersécurité, 4e année. Il est versionné et complété jour après jour.

## Observations

En modifiant le README sans faire `git add`, `git status` place le fichier
dans la zone "Changes not staged for commit" : Git a détecté que le fichier
suivi a changé, mais la modification n'a pas encore été ajoutée à l'index
(zone de staging) pour être incluse dans le prochain commit.
